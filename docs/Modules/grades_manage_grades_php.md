# Module: Grades Management (grades/manage_grades.php)

- Path: `grades/manage_grades.php`
- Audience: Admin, Developers
- Purpose: Enter and view grades and quiz scores; stats and tables.
- Access & Roles: Admin-only.

## Key UI Actions
- Add composite grade (WW 30%, PT 50%, QE 20%).
- Add multiple quiz scores per cadet.
- Search/filter grades and quiz tables.

## Data Sources
- grades, quiz_scores, users, cadet_profiles.
