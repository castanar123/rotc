# Module: Advance Officer Respondents (advance_rotc_management.php)

- Path: `advance_rotc_management.php`
- Audience: Admin, Developers
- Purpose: Manage Advance ROTC signups with edit/delete, stats by course, and recent counts.
- Access & Roles: Admin-only; logs access and actions via `SecurityLogger`.

## Key UI Actions
- View all signups, search, edit entry (name/course/facebook link), delete entry.
- Stats: total, recent 7 days, courses distribution.

## Data Sources
- advance_rotc_signups (primary)
- users (for sidebar badges)
