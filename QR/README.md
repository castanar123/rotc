# Student Attendance QR Code System

This is a web-based attendance system that uses QR codes to track student attendance. The system generates encrypted QR codes for students and provides a scanner to read these codes and record attendance.

## Features

- Generate encrypted QR codes for students
- QR codes contain student ID, name, and expiration date
- Scan QR codes to record attendance
- Select Training Day (TD) and Semester when scanning
- QR codes are encrypted and can only be read by this system
- Download generated QR codes as PNG images

## Setup Instructions

### Prerequisites

- XAMPP (or any PHP server with MySQL)
- Web browser with camera access

### Installation

1. Place all files in your XAMPP htdocs directory (or your web server's document root)
2. Import the database schema by running the SQL commands in `database.sql`:
   - Open phpMyAdmin (http://localhost/phpmyadmin)
   - Create a new database named `attendance_system`
   - Import the `database.sql` file

### Usage

#### Generating QR Codes

1. Open `index.html` in your web browser (http://localhost/generate%20qr/index.html)
2. Enter the student's ID and name
3. Set the expiration date for the QR code
4. Click "Generate QR Code"
5. Click "Download QR Code" to save the QR code as an image

> **Note:** The encryption key is now managed by the system for security and consistency.

#### Scanning QR Codes

1. Open `scanner.html` in your web browser (http://localhost/generate%20qr/scanner.html)
2. Select the Training Day (TD) and Semester
3. Click "Start Scanner"
4. Point the camera at a QR code generated by this system
5. The system will display the student information and record the attendance

> **Note:** The decryption key is now managed by the system for security and consistency.

#### Accessing from Mobile Devices (Same WiFi Network)

1. Open `network.html` in your web browser to see your computer's IP address and instructions
2. On the mobile device, open a browser and enter:
   `http://[YOUR_IP_ADDRESS]/generate%20qr/scanner.html`
   (Replace [YOUR_IP_ADDRESS] with your computer's IP address)
3. Allow camera access when prompted
4. Use the scanner as described above

> **Note:** Both your computer and mobile device must be connected to the same WiFi network for this to work.

#### HTTPS Setup for Camera Access on Mobile

Most mobile browsers require HTTPS for camera access. To enable HTTPS:

1. Open `https_test.html` to test if your camera works with your current setup
2. If camera access fails, follow the instructions in `HTTPS_SETUP.md` to set up HTTPS
3. Once HTTPS is set up, uncomment the HTTPS redirection section in the `.htaccess` file

## Security Features

- QR codes are encrypted using AES encryption with a permanent system key
- Each QR code has an expiration date
- QR codes can only be read by this system
- External QR code scanners will only see encrypted text
- No manual key entry required, ensuring consistent encryption/decryption

## File Structure

- `index.html` - QR code generator page
- `scanner.html` - QR code scanner page
- `home.html` - Main navigation page
- `network.html` - Network information for mobile access
- `https_test.html` - Test page for camera access over HTTPS
- `style.css` - Styles for all pages
- `mobile.css` - Mobile-specific styles
- `script.js` - JavaScript for the generator page
- `scanner.js` - JavaScript for the scanner page
- `config.js` - System configuration and encryption keys
- `record_attendance.php` - Backend script to record attendance (placeholder)
- `get_ip.php` - Script to get server IP address
- `db.php` - Database connection and functions
- `database.sql` - SQL schema for the database
- `HTTPS_SETUP.md` - Instructions for setting up HTTPS
- `.htaccess` - Server configuration file

## Troubleshooting

- If the camera doesn't start, make sure you've granted camera permissions to the website
- If QR codes aren't scanning, ensure they were generated by this system and you're using the correct secret key
- For database connection issues, check your XAMPP configuration and ensure MySQL is running
- If accessing from a mobile device fails:
  - Verify both devices are on the same WiFi network
  - Check if your firewall is blocking connections (you may need to allow port 80)
  - Try using HTTPS if available, as some browsers require secure connections for camera access
  - Make sure XAMPP is configured to accept external connections (check httpd.conf)
