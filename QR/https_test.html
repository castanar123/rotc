Troubleshooting

If Camera Test Fails:

  1. Check if you're using HTTPS (secure connection)
  2. Make sure you've granted camera permissions to this site
  3. Try using a different browser
  4. See HTTPS Setup Guide for instructions on enabling HTTPS
